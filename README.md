# 🌺 2027 沖繩五天四夜｜互動式客製行程規劃

**Live：https://kenhuangads.github.io/travel-tool/**　｜　存地圖頁：[savelist.html](https://kenhuangads.github.io/travel-tool/savelist.html)

跨世代家庭（預設 6 位大人、不自駕）的沖繩行程工具：勾選想去的地方，自動排出 2027/1/20–1/24 的五天行程，含每段交通、出發抵達時間與花費試算。自[釜山版](https://github.com/kenhuangads/busan-trip)延伸，排程引擎與操作方式相同。

## 怎麼用

1. **先設定**：出發機場（桃園／台中／高雄）、航班時間、住宿（9 家可選）、同行人數（2–12）。報到接送、計程車拆分台數、包車車型與費用全部跟著換算。
2. **勾選**：景點至少 3 個、美食至少 6 家，購物選填。可搜尋、依分類／區域／門市篩選，依推薦度／價格／距離排序。
3. **產生行程**：依區域動線排成 5 天時間軸——市區步行／單軌／計程車，北部與中部為包車日（含 10 小時基準與超時提醒）。
4. **微調**：每一站都能改順序（▲▼）、搬到別天（◀▶）、改時段、填預約時間、**移除（✕）**；整天可互換。採購站與自動填充的散步時段也能移除，移除的門市會退回頂部面板、隨時可排回。
5. **帶著走**：複製文字版貼 LINE、分享連結（開啟即重現同一份行程）、同步 Google 試算表、列印或存 PDF。

## 到了當地最常用的按鈕

| 按鈕 | 作用 |
|---|---|
| 📍 Google地圖・店家頁直達 | 用 Google place id 直接開到「那一家」的頁面，不靠搜尋、不會跑錯分店 |
| 🧭 Google 導航到這 | 從目前位置導航到核對過的座標 |
| 🚕 日文地址 | 一鍵複製 Google 登錄的日文地址，貼進 GO／DiDi／Uber 或直接拿給司機看 |
| 🚗 Uber 直接設目的地 | 深連結帶座標開 Uber 並設好目的地（那霸一帶可叫 Uber Taxi） |
| 🚖 下車點 | 大型景點的最佳下車處（首里城→首里杜館、齋場御嶽→物產館停車場…） |
| 📞 電話 | 一鍵複製，訂位直接撥打 |
| 📅 線上訂位 | 7 家需訂位餐廳的訂位頁（逐一開頁核對過店名與地址） |
| 🍽️ 推薦點法 | 49 家餐飲的必點／招牌／多人份量建議，附日文菜名可直接指給店員看 |

每天「回飯店」那一列與摘要卡都放了飯店地址與 Uber 鈕。

## 其他功能

- **單軌票券建議**：逐日加總單軌票價並套用「感應式信用卡每日封頂 800 円」，直接回答要不要買一日券。
- **PDF 版面**：iPhone 列印預覽會拿掉超連結，改用「📄 PDF 版面」再以 Safari 分享存 PDF；每一站另印一行短網址，PDF 裡點得動。
- **存進 Google 地圖（savelist.html）**：逐家直達商家頁按儲存、打勾追進度；另可下載 My Maps 匯入 CSV（含座標、日文地址、電話、商家頁連結）。
- **排不進的門市面板**、**sticky 快速跳日列**、**空檔建議**、**備選一鍵換進正選**、**版本草稿**等沿用釜山版。

## 資料說明

- 內容取自 2027 沖繩跨世代家庭研究報告、2026 沖繩觀光消費白皮書與 2026 沖繩深度旅遊洞察報告（社群非業配清單），逐項網路查證後入庫：35 景點、63 餐飲、74 購物品項、21 採購門市、9 家住宿。報告中查證不符的內容（店址寫錯、分店已歇業、商品出處不對）一律以實查為準並在卡片上註明；宮古・石垣限定的項目不在本島行程範圍，未收錄。
- **座標總校正（2026/10/5）**：101 個地點以 Google 地圖第一筆結果為準，再用國土地理院地址反查與 OpenStreetMap 交叉驗證。校正前 98 個偏差超過 40 m、16 個超過 1 km（最大 5 km）。
- **推薦點法的價格**是 2025–2026 網路查到的約略值（標「約」），以現場為準。
- **營業時間**：2026/8–10 三輪查證；店家時間會變動，出發前請重跑複核（見下）。JUNGLIA 2027/1 的營業時間未能從官方月曆確認，暫沿用 10:00–19:00。
- 價格以 100 日圓 ≈ NT$21 換算。

## 維護

- 純靜態網站：`index.html`＋`savelist.html`＋`assets/`（`data.js` 資料、`app.js` 排程與畫面、`style.css`）。勾選狀態存 localStorage，行程可由網址參數還原。
- **每次改動都要同步改版本號**：`data.js` 的 `CONFIG.build`、`index.html` 的三個 `?v=`、`savelist.html` 的一個 `?v=`。
- **出發前複核**：`node tools/audit_places.js`——逐一比對座標、Google place id、歇業狀態與每週營業時間，只列出有出入的項目（`--refresh` 重抓、`--only s01,f17` 指定項目）。目前列出的差異多為季節性營業時間或刻意保守的時段，改資料前請再以官網確認。
- push 到 `main` 即由 GitHub Pages 自動部署。
